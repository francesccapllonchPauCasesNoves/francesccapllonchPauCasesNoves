## Català

### 📌 Sobre el Projecte
Aquest repositori conté el codi font del meu **portafoli i CV interactiu**. Inclou una interfície web moderna desenvolupada amb una estètica de consola interactiva/terminal (*CachyOS Dev Shell*) combinada amb un CV tradicional, suport multiidioma (Català, Castellà i Anglès) i disseny completament *responsive*.

### 👨‍💻 Sobre mi
Soc estudiant de **Desenvolupament d'Aplicacions Multiplataforma** al **CIFP Pau Casesnoves** (Mallorca). Tinc experiència prèvia com a Tècnic en Sistemes Microinformàtics i Xarxes i un fort interès en el desenvolupament de programari, la ciberseguretat i les tecnologies web/mòbils.

### 🛠️ Tecnologies Utilitzades
* **Front-End:** HTML5, CSS3, JavaScript (ES6+), Tailwind CSS.
* **Estils & Fonts:** Google Fonts (Roboto Mono, JetBrains Mono, Fira Code).
* **Internacionalització (i18n):** Sistema de traducció en client (`translations.js`).
* **Llenguatges & eines de desenvolupament:** Java, Dart / Flutter, SQL (MySQL), NoSQL (MongoDB), Git & GitHub.

### 🚀 Projectes Destacats
1. **EcoRide (Dart):** Projecte d'exemple i desenvolupament en Dart.
2. **Log Filter (Java):** Sistema de filtratge de registres desenvolupat en Java.
3. **Flutter Example:** Aplicació i exercicis pràctics desenvolupats amb Flutter.

### 📜 Certificacions
* Tècnic en Sistemes Microinformàtics i Xarxes (EQF Nivell 4).
* Cisco: Introduction to Packet Tracer.
* Cisco: Introduction to Cybersecurity.
